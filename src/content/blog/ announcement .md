# Stop editing production AI workflows directly

<p class="badge-row" style="font-weight: bold">
  Private Alpha · Versioned Capsules · Managed · Community · Appliance
</p>

Qiln runs **agent-safe, versioned AI workflow capsules**.

We are starting with one production blueprint:

> **One loop: fork → edit → test → diff → promote/rollback.**

n8n handles triggers, SaaS integrations, webhooks, approvals, business logic, and orchestration.

ComfyUI handles the generative graph.

Qiln keeps the full system together as one durable capsule: workflows, graphs, custom nodes, private models, folders, routes, endpoint schemas, secret references, tests, runtime state, side-effect logs, and rollback metadata.

The promise is simple:

> **Humans and agents get forks. Production stays protected.**
